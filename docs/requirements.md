# 像素蛋糕产品知识库需求文档

## 1. 核心用户
像素蛋糕产品的客服、销售、运营和营销人员。
* **目标：** 简单方便地获取产品相关的功能、卖点和使用场景等知识。
* **差异化需求：** 根据不同的客服、销售、营销和运营视角，定制化展示或生成专业的产品知识、营销策略、销售话术。

## 2. 项目背景
像素蛋糕是一款专为商业摄影服务的 AI 修图软件。
* **痛点：** 软件功能繁多，迭代速度极快（版本更新频繁），不同摄影场景（婚纱、儿童、全家福等）需求差异大。
* **挑战：** 新员工和一线人员难以跟上版本更新速度，难以在销售/服务中准确传达针对特定场景的卖点和功能效果。

## 3. 功能需求详情

### (1) 知识展示与交互（前端核心）

#### A. 多模态知识展示（必须支持图文）
* **图文混排：** 鉴于修图软件特性，知识库必须支持图片/GIF展示。
* **效果演示：** 当查询某个修图功能（如"磨皮"、"换天空"）时，AI 给出的答案不仅要是文字，必须包含对应的**效果对比图**（Before/After）或**操作演示 GIF**。

#### B. 智能问答与检索 (RAG)
* **自然语言交互：** 支持自由提问（例如："如何向儿童摄影客户介绍调色功能？"）。
* **精准引证：** 为确保准确性，AI 的回答必须在末尾标注**"参考来源"**（例如：*引用自《V5.2版本功能说明书》*），支持点击跳转查看原文。
* **防幻觉机制：** 设置置信度阈值，对于知识库中不存在的信息，AI 应明确回复"知识库暂未收录"，严禁编造功能。

#### C. 预置提示词与场景化模板
**核心逻辑：** 用户选择场景 -> 系统弹出表单提醒输入必要信息 -> AI 结合输入信息与知识库生成答案。

根据业务需求，第一期预置以下三个核心模板：

**场景一：客服快速响应**
* **目标：** 帮助客服快速了解功能详情，并生成标准回复。
* **输入表单项：**
    1. **功能名称/关键词**（必填，如：联机拍摄功能）
    2. **用户具体问题**（选填，如：像素蛋糕的联机拍摄是否支持索尼A7M4？）
* **系统处理逻辑：**
    * 检索该功能的详细说明文档（包含操作步骤、注意事项）。
    * 生成两部分内容：一部分是给客服看的**"功能详解"**（帮助理解），另一部分是直接发给用户的**"标准回复话术"**。

**场景二：运营推广策划**
* **目标：** 针对特定功能或活动，产出卖点总结与营销文案。
* **输入表单项：**
    1. **推广功能/核心卖点**（必填，如：调色功能、AI祛路人）
    2. **推广活动/背景**（选填，如：双11大促、新品发布）
    3. **营销推广目标**（必填，如：提升用户活跃度、吸引婚纱客户）
* **系统处理逻辑：**
    * 检索该功能的所有核心卖点、技术优势。
    * 输出结构化的营销方案：
        * **全方位卖点总结**（功能性卖点+情感化卖点）。
        * **适用推广场景**（如：样片宣发、门店体验日）。
        * **营销宣传语**（包含短句 Slogan 和长篇种草文案）。

**场景三：销售策略定制**
* **目标：** 针对不同类型的摄影客户，提供定制化的攻单策略。
* **输入表单项：**
    1. **客户类型**（必填，如：儿童摄影、婚纱影楼、独立摄影师）
    2. **客户关键信息/痛点**（选填，如：在乎修图效率、对肤色要求高、目前使用竞品A）
* **系统处理逻辑：**
    * 检索针对该客户类型的成功案例和适用功能。
    * 输出针对性策略：
        * **推荐功能组合**（例如对儿童摄影推荐"婴儿面部祛瑕疵+牙齿美化"）。
        * **核心话术策略**（如何直击痛点）。

### (2) 管理员后台（CMS）

#### A. 文档资源管理
* **多格式支持：** 支持上传 Markdown/PDF/WORD 文档，支持在文档中插入图片或视频链接（用于前端效果展示）。
* **版本标签管理：** 上传文档时需支持打上"软件版本号"标签（如 v5.0, v5.1），确保回答的时效性。
* **增删改查：** 基础的文档维护功能。

#### B. 提示词模板管理
* **模板编辑器：** 允许管理员编辑 Prompt 模板的提示词指令。
* **表单配置器：** 管理员可自定义上述场景中的输入项和必填/选填属性。

## 4. 典型使用流程 (User Flow)

以运营推广调色功能为例：
1. **运营人员**登录知识库，点击"工具箱"中的"运营推广策划"模板。
2. **系统弹窗提醒输入：**
    * 推广功能：*像素蛋糕调色功能*
    * 推广活动：*近期主推"胶片风"滤镜*
    * 营销目标：*吸引更多追求风格化的独立摄影师*
3. **点击生成**。
4. **系统后台**在知识库中检索"调色"、"滤镜"、"独立摄影师需求"相关文档。
5. **系统输出结果：**
    * *卖点总结：* "AI 智能匹配色彩，一键还原胶片质感，无需手动调节曲线..."
    * *推广场景：* "建议在小红书发布'原片直出vs胶片感'对比视频..."
    * *宣传语：* "告别繁琐调色，像素蛋糕还你摄影本质。"
6. 运营人员参考该内容制作海报和推文。

## 5. 非功能性需求
* **准确性：** 功能信息必须严格准确，必须有引用来源，不能由 AI 随意发散。
* **易用性：** 界面 UI 需美观现代，操作逻辑简单，降低非技术人员的使用门槛。
* **账号体系：** 基础的登录/注册功能，保障内部资料安全。
